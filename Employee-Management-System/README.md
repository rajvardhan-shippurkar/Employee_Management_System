# Employee Management System

A Java-based desktop application for managing employee records using Java Swing and MySQL.

## Features
- Admin login
- Add employee details
- View and search employee records
- Update employee information
- Remove employee records
- Print employee details

## Technologies Used
- Java
- Java Swing (GUI)
- MySQL
- JDBC
- NetBeans IDE

## Database Setup
1. Install MySQL Server and MySQL Workbench.
2. Open MySQL Workbench and execute the SQL script in `database.sql`.
3. Update the database username and password in `Conn.java` to match your local MySQL configuration.

## How to Run
1. Download or clone this repository.
2. Open the project in NetBeans IDE.
3. Add the required libraries: MySQL Connector/J, JCalendar, and `rs2xml.jar`.
4. Configure the MySQL connection in `Conn.java`.
5. Build and run the project.
